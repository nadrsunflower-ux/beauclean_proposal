# 뷰클린 매출 성장 제안서 (웹 슬라이드)

`GL-AI-STUDIO_뷰클린_매출성장_제안서.pdf`를 16:9 슬라이드 34장으로 옮긴 웹사이트입니다.
Next.js 16 · Tailwind CSS 4 · Framer Motion.

## 실행

```bash
npm install
npm run dev        # 수정하면서 볼 때 → http://localhost:3000
npm run build && npm run start   # 발표용(빠름)
```

## 조작

| 키 | 동작 |
|---|---|
| `→` `Space` `PageDown` | 다음 장 |
| `←` `Shift+Space` `PageUp` | 이전 장 |
| `Home` / `End` | 처음 / 마지막 장 |
| `G` | 전체 보기 (썸네일 클릭으로 이동, `Esc`로 닫기) |
| `F` | 전체 화면 |

- 아래쪽 폴더 탭(01~08)과 목차를 누르면 해당 장으로 이동합니다.
- 주소 끝의 `#번호`가 현재 장입니다. 새로고침해도 같은 장이 열립니다.
- 터치 화면에서는 좌우로 밀어 넘깁니다.
- 마우스로 무언가를 누른 뒤에도 `Space`는 장 넘김으로 동작합니다. `Tab`으로 고른 조작부에서는 `Space`가 그 조작부를 누릅니다.

## 디자인 규칙

- 크림 종이 바탕, 파란 폴더, 차콜 카드 (UI 코어 스타일)
- 폴더 = 실제로 구분되는 묶음(장·채널·패키지), 탭을 누르면 그 묶음으로 이동
- 차콜 체크 카드 = 확정된 것(점검 기준·승인·약속)
- 회색 원 = 근거 숫자, 신호등 점 = 근거 표시(초록 확인 · 노랑 영상 · 회색 가정 · 빨강 미확인)
- 브라우저 창 틀은 실제 화면(상세페이지·대시보드) 예시에만

## 구조

```
src/slides/index.ts          장 순서 (여기서 추가·삭제·순서 변경)
src/slides/sections.ts       8개 장 이름·목차 설명
src/slides/data.tsx          시나리오·레버·패키지 데이터 (차트와 표가 함께 씀)
src/slides/intro.tsx         표지 · 한 장 요약 · 목차
src/slides/s01~s08-*.tsx     장별 슬라이드 내용
src/components/deck/         1920×1080 캔버스, 머리줄, 폴더 탭, 전체 보기, 패키지 선택 상태
src/components/ui/           카드·폴더·원·근거 배지·스위치·슬라이더 등 공통 요소
src/components/charts/       시나리오·폭포·비교 막대 차트
```

슬라이드는 1920×1080 캔버스에 그린 뒤 화면 크기에 맞춰 통째로 확대·축소하므로,
글자 크기는 px로 지정합니다.

Tailwind CSS 4 기준이라 Safari 16.4 이상에서 정상 표시됩니다.
